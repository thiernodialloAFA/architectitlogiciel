# Governance Platform — Frontend

React 19 + TypeScript + Vite SPA for the Architecture Governance Platform.
See [`../README.md`](../README.md) for the full app documentation, run
instructions (Docker Compose) and local development workflow.

```bash
npm install
npm run dev     # http://localhost:5173, proxies /api to localhost:8080
npm run lint    # oxlint
npm run build   # tsc -b && vite build
```
